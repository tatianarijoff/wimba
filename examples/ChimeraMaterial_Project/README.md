# ChimeraMaterial_Project

A [parametric project](../../docs/PARAMETRIC.md): CHIMERA at injection
(γ = 2.279), with the innermost layer of both collimators, COLL.H and COLL.V,
made of six materials in turn — copper, aluminium, molybdenum, titanium,
stainless-steel-316ln, graphite. Everything else is the base config,
`../Chimera_Project/injection_config.yaml`, whose data this project reads by
relative path: keep the two folders side by side.

Open it with *File → Open Project*, then *Calculate → Calculate Project…*.
Plot `Re ZDipX` of COLL.H across the six cases, then the total: the first shows
what the material does to the collimators, the second whether the ring notices.

CHIMERA is invented. Do not quote a number out of it.
